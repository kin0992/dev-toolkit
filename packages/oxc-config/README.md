# @kin0992/oxc-config

Shared OXC formatter and lint configuration.

## Install

```sh
pnpm add -D @kin0992/oxc-config oxfmt oxlint
```

## Use

```ts
// oxfmt.config.ts
import config from '@kin0992/oxc-config/oxfmt';

export default config;
```

```ts
// oxlint.config.ts
import config from '@kin0992/oxc-config/oxlint';

export default config;
```
